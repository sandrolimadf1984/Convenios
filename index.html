Verificador de Convênios

Instale em 1 minuto · Sabin Brasília

1

Mostre a barra de favoritos

Pressione Ctrl + Shift + B no Chrome para exibir a barra de favoritos.

2

Arraste o botão para a barra de favoritos

Segure o botão abaixo com o mouse e arraste até a barra no topo do Chrome.

⬇ Arraste este botão para a barra de favoritos ⬇
📋 Convênios
👆 Clique e segure → arraste para cima até a barra
3

Pronto! Clique no favorito para usar

Abra qualquer portal de autorização e clique em 📋 Convênios na barra.

✅ Como funciona:
Clique no favorito → a ferramenta abre por cima do portal
Digite o convênio → veja validade, ressalvas e anexos da Shift
Informe a data do pedido → diz se está VÁLIDO ou VENCIDO
Clique FECHAR para sair.
